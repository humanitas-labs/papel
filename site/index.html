Paper

A quiet, native macOS editor for ordinary Markdown.

Download for MacSourcemacOS 15 or later · free, MIT

One document

Paper shows one document at a time. There is no sidebar, no tab strip, no outline, no word count, no toolbar. The window is the page and the page is your file. A second file gets a second window, the way the Mac has always done it.

Most editors are built for managing writing. This one is built for doing it. Everything that isn't the text has been taken off the page, so that what remains is the sentence you are working on.

The file, as written

Markdown was made to be read as source. Paper keeps that promise and styles the text in place:

  • Typography — a centred measure with real margins; headings stepped from the body size; block quotes inset and italic behind a rule.
  • Lists — - draws as a dashed list (–), * as a bulleted one (•). Items hang under their text, and Return continues the list.
  • Code — fenced blocks set in mono on a quiet band, their fences tucked away; inline code in mono too.
  • Links — underlined words with the syntax concealed until the caret arrives. Click opens the destination; #anchors jump within the document.
  • Images — files beside the document draw in place. Remote ones stay as their alt text; Paper never makes a network request.

The styling is drawn over your text, never written into it. What you save is exactly what you typed, byte for byte, and every other tool reads it the same way.

A Mac app in the plain sense

Native text on AppKit, so the system's spelling, dictation, and shortcuts work the way you expect. It opens the moment you double-click, and reloads when something else edits the file on disk.

That reload makes Paper a good surface for writing done by an agent. Point Claude at a file, open it in Paper, and watch the document take shape as it is written. How to set that up.

Yours to tune

Font, size, measure, line height, and theme live in one plain text file, applied live to open windows whenever it is saved. Five themes ship, each with a light and a dark palette; your own is another file in the same folder.

font.family = New York
font.size = 14
line.height = 1.38
measure = 640
theme = paper

A small launcher rides along for the terminal: paper notes.md opens a document, creating it first if it doesn't exist.

Why

It is easy to dismiss the medium, but the tools we write with shape what we write. Paper is an experiment in taking everything away and seeing what the writing does.
